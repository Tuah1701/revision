iPad alerts · one-time setup

When you press Start, the timer hands your warnings to a Shortcut, which puts them in Reminders. They pop up even while you're in another app. Pause, Finish, Reset and switching paper clear them.

  1. In Reminders, make a new list called Exam Timer.
  2. In Shortcuts, tap + and name the shortcut Exam Alerts (exactly).
  3. Add Find Reminders: tap Add Filter → List is Exam Timer. Then add Remove Reminders under it.
  4. Add If: Shortcut Input → has any value. Put steps 5–9 inside the If.
  5. Add Split Text: split Shortcut Input by New Lines.
  6. Add Repeat with Each (item in Split Text). Put steps 7–9 inside it.
  7. Add Split Text: split Repeat Item by Custom → type |. Then add Get Item from List → First Item.
  8. Add Adjust Date: Add → tap the number and pick Item from List, unit seconds, to Current Date.
  9. Add Get Item from List → Last Item, and tap its input to pick the Split Text from step 7. Then add Add New Reminder: title Item from List, list Exam Timer, turn on Remind Me → At Time → pick Adjusted Date.
  10. In the shortcut's settings (ⓘ) → Privacy, allow deleting without asking. Check Reminders notifications are on in iPad Settings.

After each Start or Pause you'll briefly see Shortcuts; swipe back to the timer. Alerts land within about a minute of the exact time, and a Focus mode can silence them.

Sync between Mac and iPad · one-time setup

Your saved papers go into a private (secret) gist on your GitHub account, so a paper you pause on the Mac is waiting on the iPad, and the other way round. Do step 1 once, then step 2 on each device.

  1. On github.com: your photo → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic). Note: Exam Timer. Expiration: No expiration (or a year). Tick only gist. Generate, then copy the token (starts ghp_). Keep it in Notes or iCloud Keychain so you can paste it on the other device.
  2. Paste it below and tap Connect. Do the same in the app on your other device.

The token can only read and write your gists, and it stays on this device. To stop syncing here, tap Disconnect.

Every paper keeps its own clock, and with Sync on it follows you between Mac and iPad. Pick another paper at any time: the one you were on pauses and is saved (dot ●), ready to continue later from Saved. Only Reset or New test clears a paper.
